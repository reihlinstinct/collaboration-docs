# parking-stats

Scope: the statistics tool and its public site. This skill grants no new
task, account access, spending or publishing permission.

## What this solution is

[parking-stats](https://github.com/reihlinstinct/parking-stats) turns a
Jerusalem 106 reports export into aggregate statistics, charts and a public
GitHub Pages site. It is generated by `p106-stats` from
[parking-report-helper](https://github.com/reihlinstinct/parking-report-helper)
and publishes aggregates only: counts by month, week, category, street,
neighborhood and hotspot, plus closure-time summaries.

## Operating rules

- Aggregates only: never raw export data, names, case descriptions or any
  per-case detail in the repo, issues or PRs. The CI privacy scan enforces
  this on every push and PR.
- Raw exports are processed locally and never enter the repo; the publisher
  re-scans every file and refuses to publish on any finding.
- Publishing real data needs the owner's OK each time. The repeat-plates
  aggregate (canonical plate plus report count) is the one owner-approved
  exception, as the README records.
- The site updates manually; say when data is stale rather than implying a
  live feed.
